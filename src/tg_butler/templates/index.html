导入历史消息

                
将最近若干完整自然日（不含今天）的群消息导入本地数据库，按消息 ID 自动去重，单次最多扫描 5000 条。

监控群组

                
管理已加入的群组监控、关注用户及双机器人通知分流策略。

              

              

                
                
                
              

            


            
筛选关闭时，「关注-日报机器人」推送关注用户的每条发言；开启后，「自定义机器人」仅推送命中关键词、图片或链接规则的消息并附带原消息（多条件为“或”关系）。


            


            

              
            

          

        


        
        

          

            

              

                
定时签到

                
按运行设置中的时区每天发送一次签到命令，并可选监听群内机器人回复进行成功确认。

              

              

                
                
                
              

            


            
群组 ID 与回复机器人 ID 可在「查找群组与 ID」页查询。同一任务名称每天仅执行一次，修改名称会视为新任务；测试签到真实发送命令，但不占用当天正式签到次数。


            


            

              
            

          

        


        
        

          

            

              

                
每日日报与 AI 摘要
