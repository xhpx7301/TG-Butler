账号应用凭据
用于登录你的个人 Telegram 账号，读取已加入的群消息、发送签到命令。与通知机器人的 Token 不同。




登录 Telegram 账号
先保存上方应用凭据。验证码由 Telegram 提供，可能发送到已登录的 Telegram 客户端。验证流程 5 分钟内有效。






手机号、验证码及两步验证密码只用于登录。请通过 SSH 隧道或 HTTPS 访问。


导入历史消息
历史导入范围为最近几个完整自然日，不包含今天。默认导入前一天，适合生成测试日报；消息会按消息 ID 去重，最多扫描 5000 条。
群组 ID 请在“群组与关注用户”页查询。




通知机器人
关注-日报机器人发送关注用户的全部消息、每日日报和签到结果；自定义机器人仅发送命中关键词、链接或图片规则的关注消息，并附上原消息。两个机器人都需要先向它发送 /start。
关注-日报机器人
自定义机器人
要复制原消息（含图片、文件等），请将自定义机器人加入对应来源群组并确保它可以读取消息。升级旧版本时，原有 TG_BOT_TOKEN / TG_NOTIFY_CHAT_ID 会作为两个角色的回退配置；分开配置后即可分别使用。


查找群组与用户 ID
输入公开群组链接或用户名，快速获取群组 ID；输入用户 @用户名获取用户 ID。
公开群组链接和用户名需要账号可以访问；私密邀请链接无法直接解析。成员可见范围由群权限决定，匿名发言无法识别隐藏的个人身份。
监控群组
填写账号已加入的群组 ID，并选择关注谁的发言。
关注-日报机器人发送关注用户的每条消息。自定义机器人仅在关键词、图片或链接规则命中时发送提醒，并附上原消息；多个条件之间是“或”，关键词可选择任一或全部匹配。


每日日报
汇总前一天的本地消息。默认提供数量统计和消息摘录；配置 AI 后可生成话题总结。
AI 服务密钥


定时签到
按配置时区，每天发送一次指定命令。
群组 ID、签到机器人 ID 可在“Telegram 账号”页查询；命令与回复关键词请以群内机器人的帮助信息为准。同一任务名称每天只尝试一次，修改名称会被视为新任务。测试会真实发送签到命令，但不会占用当天正式签到次数。


运行设置
网页监听地址、端口和 HTTPS Cookie 选项请在 bu → 1 网页后台 → 3 监听设置 中管理。默认只监听本机 127.0.0.1:15678。


管理员账户
当前为单管理员模式，网页与 bu 管理同一账户。此账号仅用于后台登录，与 Telegram 账号独立。
